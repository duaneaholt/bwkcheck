# bwkcheck.ps1
###### ### -by Duane Holt

Bitwarden password checker for known exposed passwords.  Powered by HaveIBeenPwned public API.  

Requires: Powershell

Bitwarden Export, either a .json file or bitwarden cli

Optional:  Automatic checking via BW cli (the Bitwarded API). Download and the bw cli, login and then start bwkcheck

Just released after putting together this week.  May get more attention if this gets popular.
